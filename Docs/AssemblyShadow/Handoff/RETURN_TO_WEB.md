### Root cause

The authority repair models only the three outer-wrapper recovery paths as workflow mutable. Native-ON Player generation also rewrites the tracked HybridCLR generated linker file. The next full guard therefore treats legitimate build-generated content as arbitrary source drift. The design allowed this because the repaired integration coverage proved post-`ValidateCompilerInputs` authority but did not exercise the next guard after a real Player build with the tracked generated linker input.

### Impact

Normal M07 cannot reach Native-OFF Player, structural recovery, fixture finalization, or Editor replay. Startup11, the 8192/8193 boundary, retained coverage, controlled performance, V05 successor packaging, and independent whole-chain M08 remain blocked. Human Review Gate is not ready and R02 remains closed.

### Recommended direction

Review ownership of `Assets/HybridCLRGenerate/link.xml` across M07 Player generation and source authority. Prefer a contract that snapshots and authenticates its pre-build bytes, proves the exact generation action and output, and restores it on every exit, or moves the generated output outside the immutable tracked-input surface. Extend real integration coverage through the post-Native-ON guard and the full normal M07 chain. Do not add a broad generated-directory allowance or weaken generic source verification.

### Uncertainty

This run proves resource generation and Native-ON Player generation succeed. It does not establish Native-OFF, structural fixtures/replay, or downstream runtime and performance behavior because the guard stops the workflow immediately afterward.
