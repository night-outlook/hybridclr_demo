## Native production implementation

- New `libil2cpp/vm/AssemblyShadowOwnedPhysicalNames.h` defines a noncopyable, one-use, fixed-capacity `Capture`: at most **1,024 matched classes**, **256 KiB owned raw name text**, no field exceeding **4,096 bytes**, and object size `<=512 KiB`. Each row contains bounded spans for `physicalAssemblyName`, `nameSpace` and `simpleName`. These are independently copied raw physical metadata names, not a serialized type key; no managed callback or dynamic allocation occurs in `Add()`.
- An explicit `Begin → Add* → Seal` lifecycle rejects reuse, missing/overlong names, aliasing with the mutable owned capture, row/text overflow and wrong phase. `Get` returns views into **the capture's own copied buffer**, not `Il2CppClass*`, `Il2CppImage*`, `Il2CppAssembly*` or borrowed metadata text. Failures revoke the entire capture and clear partial text/rows.
- `AssemblyShadowPhysicalMembership.h` adds an `ObservationEvent` classification for `Ignored`, `FirstMatch`, `DuplicateMatch`, `Invalid` while preserving the old `void ObserveEnumerated` API through delegation. The existing physical-membership method does not dereference class fields or change its original counting semantics. The owned-name callback reads physical name fields **only on a first witnessed, observed physical iterator match**. Unrelated, even invalid, pointer values from enumeration are ignored without dereferencing.
- New real `AssemblyShadow::TryCaptureOwnedObservedPhysicalNames(membership::Scratch&,owned::Capture&,owned::Receipt&)` is declared behind the original Assembly Shadow feature switch and included exactly once by `AssemblyShadow.cpp`. No existing getter, managed caller or Player invokes it. It obtains one **initial-session-only MetadataLifetime Reader**, copies/reviews the bounded registry under `ExecutionObservationLock`, releases that lock, then calls the original `il2cpp_class_for_each` **under `g_MetadataLock`**, and finally releases metadata lock before rechecking all registry witnesses/slots/revision and active/state samples under their original short lock.
- During a *first matched callback* only, the method borrows `klass->image->assembly->aname.name`, `klass->namespaze`, `klass->name` and copies their complete bounded byte spans into caller-owned capture storage while the metadata lock is held. It retains **no raw source pointers** after the callback. Null namespace is treated as empty; missing image/assembly/required names, invalid enumerator callbacks, incomplete physical membership, wrong row count, source changes and all owned-buffer errors fail closed. Partial buffer data is revoked after releasing the metadata lock.
- The receipt exposes only counters, text bytes and `namesCopiedFromMatchedEnumeratorCallbacks=true` on success. **Always false**: `classPointerOwnershipProven`, `metadataPointerLifetimeProven`, `completeExecutionTypeKeys`, `coherentVmEpochProven`, `playerExecution`, `runtimeAcceptance`.
