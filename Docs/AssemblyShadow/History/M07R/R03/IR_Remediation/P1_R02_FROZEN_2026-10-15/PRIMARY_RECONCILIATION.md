- libil2cpp/vm/AssemblyShadowFrozenR02Capture.h adds a one-shot fixed 8192-byte R02 suffix snapshot. Its caller must invoke Freeze at a separately reviewed, healthy, single-owner source capture boundary. Freeze serializes the complete R02 JSON suffix through the same producer into owned fixed bytes and exposes the entire immutable span if and only if the writer completed, byte size matches and the expected R02 prefix is present. Invalid output, capacity failure and second-use attempts fail closed; no prefix or missing suffix can count as complete. A second Freeze poisons reuse, not an accepted repeated observation. It makes **no VM metadata calls and no dynamic allocation** in the formatter/snapshot itself, but still uses independently sampled counter values.
