## Objective and implementation

This task advances the previous [offline census contract](B2_ROOT_NONROOT_CENSUS_CONTRACT_2026-11-16.md) by implementing a **host-only C++11 trace recorder**, not a Unity metadata producer. It uses the already tested, test-only `CapacityCandidates/BoundedHandlePatriciaIndex.h` (no change to that header or the existing storage candidates). Added files:

- `Tools/AssemblyShadow/R03IR/TypeDefCensus/BoundedNativeCensusProducer.h` — explicit `Prepare`, `Add`, `MarkUncovered`, `EndCapture`, `EmitJson`, `Release`. An `Add` receives only an opaque native handle equality key, owner/first-owner image ordinals, explicit root/nonroot role, integer metadata indices and **byte lengths**, without copying names or dereferencing the handle. The producer maps handle keys to sequential 1-based temporary IDs; a handle used in both roles has one distinct identity and two occurrence events. Duplicate identities must match all copied metadata scalars, or capture becomes incomplete.
- `BoundedNativeCensusProducerHost.cpp` — standalone synthetic C++ driver; **must never be added to a Unity/libil2cpp production source roster**. Includes complete and incomplete JSON fixture modes.
- `.github/workflows/r03-b2-native-census-producer-host.yml` — macOS/Linux × C++11/C++17, strict and ASan/UBSan compilation, synthetic test and **actual checked-in Python analyzer** cross-check.

The collector is independently bounded at **1,024 distinct handles / 4,096 event occurrences**; these are **prototype limits, not actual-game high-water marks**. The former B2 combined 128-handle limit is not copied. `Prepare` reserves arrays and the Patricia index before any prospective metadata lock. `Add` performs no dynamic allocation, file IO or string formatting, and indexes opaque keys without dereference. `EndCapture` must be invoked after a source-lock exit; it zeroes the handle index, leaving only temporary integer IDs and scalar event fields. `EmitJson` allocates/formats **after** that point and labels its JSON `captureKind=UnverifiedSource`, compatible with `analyze_typedef_census.py`.

First error wins. Invalid owners, conflicting declaration metadata, over-capacity, event overflow or `MarkUncovered` stop capture, scrub the raw-handle index and force JSON `complete=false` / `droppedEvents>=1`. Earlier accepted scalar events are preserved only as an **unverified lower bound**, never as a positive source or acceptance receipt. The format does not expose addresses or original namespace/name strings.
