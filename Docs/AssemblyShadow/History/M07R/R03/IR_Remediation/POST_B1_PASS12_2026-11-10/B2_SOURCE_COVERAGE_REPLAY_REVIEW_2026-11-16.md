## Objective, actual source boundaries and key distinction

The previous [original-V1 owner adapter](B2_ORIGINAL_V1_OWNER_SOURCE_SEAM_REVIEW_2026-11-16.md) selects the first owner of each supplied TypeDef handle using a synthetic copy of original token-valid physical image order, then feeds the unintegrated length-only producer. However, merely validating every **supplied** handle cannot establish that every **required** root/nonroot use site was enumerated. The actual inactive native B2 source `il2cpp_plus/libil2cpp/vm/AssemblyShadowBoundedDefinitionExecutionLiveSource.inl` uses:

| Actual source path | Relevant bounded native behavior | Prototype coverage tag |
|---|---|---|
| Main observed-class `buildDefinition` | Attempts the class root and resolves original first owner before a 128-pair audit | `ClassRoot` |
| `buildDefinition` declaring-type loop | Walks nested TypeDef ancestry; rejects unsupported and cyclic ancestry | `DeclaringAncestor` |
| `Composer` generic class definition | Builds generic outer definition before formatting class arguments | `GenericDefinition` |
| `Composer` constructed/general generic argument | Formats each argument recursively, including nested generic instances | `GenericArgument` |
| `Composer` class/valuetype under pointer/array/qualified tree | Resolves definitions along composite branches | `CompositeClassLeaf` |
| `Composer` default primitive mapping | Calls `Peek` for existing primitive class and resolves its physical TypeDef | `PrimitiveDefault` |

These categories are **test-only plan labels**, not exhaustive runtime callback instrumentation. Other native source exits occur before TypeDef owner resolution (e.g., unsupported open generic/VAR/MVAR/array/type shape, missing primitive default, classes not enrolled into B2). A plan derived only from existing successful `resolveOwner` calls remains selection-biased. Neither matching a two-pass plan nor serializing `complete=true` proves that absent paths were discovered or that a VM epoch exists.

## New isolated implementation

- `Tools/AssemblyShadow/R03IR/TypeDefCensus/TypeDefSourceCoverageReplay.h`: self-contained C++11 `Replay` owning the existing **host-only** `Producer` and `OriginalV1OwnerSourceAdapter`. `Prepare` preallocates three class bit vectors/arrays, a bounded site plan, the existing Patricia index and producer events **before** any prospective metadata source lock. No path planning, replay, owner lookup or closure allocates or formats. Raw opaque handle values are retained only inside the underlying producer during the collecting phase, never in plan slots or serialized output.
- **Discovery phase:** `PlanClass` enforces dense unique class slots; `PlanUse` records one typed source-use obligation per caller-enumerated occurrence, with a stable one-based site ID. Every planned class must carry exactly one `ClassRoot` site. `SealPlan` rejects counts below the caller-specified expected classes and source-site cardinalities. This is a structural comparison to caller assertions, not a proof of independently authenticated discovery.
- **Replay phase:** `VisitClass` forbids duplicate or unknown class callbacks. `VisitUse` must match the same site ID, class slot, path category and role; the source adapter then independently checks the supplied **original V1 first-match image** and forwards the observation to the bounded producer. A TypeDef reused as root and generic argument produces two occurrence events with one distinct opaque handle ID. Duplicate site visits, replay gaps, differing path/role claims, changed metadata-owner claims and unsupported/rejected paths call the existing `MarkUncovered` fail-closed sequence.
- **Close and lifetime:** `CloseAfterSource` only succeeds after all declared classes and use sites have replayed; it delegates to the previous adapter/producer close path which scrubs all retained native handle keys. Destruction or `Reset` during an open plan/replay aborts. Late `MarkUnsupported` revokes an in-memory completed trace. `EmitJson` is only callable following closure or failure, never from an active source callback. It outputs `UnverifiedSource`; the offline analyzer always leaves provenance/epoch/capacity/product flags false.
- `TypeDefSourceCoverageReplayHost.cpp`: deterministic synthetic regressor and complete/incomplete fixture producer; it is **not** added to any Unity native source roster. `.github/workflows/r03-b2-typedef-source-coverage-host.yml`: isolated macOS/Linux × C++11/C++17 strict+ASan/UBSan matrix, including the actual checked-in Python analyzer on both fixture states.

**Prototype bounds:** 1,024 classes, 4,096 planned use sites/events, 1,024 distinct TypeDef handles, at most 1,024 supplied original-V1 physical images, and 1,000,000 synthetic owner lookups. Exceeding the distinct handle limit yields an `IncompleteLowerBound` trace rather than a selected capacity. The currently inactive native B2 **128 combined handle**, two 64-byte name and **65,536 owner-lookup** bounds are unchanged.

## Primary review findings and mandatory stopping point

- **COVERAGE-01 — host scope passed:** Exact site/class counts and typed role plan **cannot** complete when an *already planned* site is missing, duplicated, invalid, rejected or owner-unverified. First error wins, and retained pointer-equivalent index values are scrubbed. This is stronger than a producer driven solely by successful `AddUse` callbacks.
- **COVERAGE-02 — OPEN / HIGH:** Discovery and replay are both caller-driven. They can omit the same real TypeDef path and still agree. This does **not** prove independent all-class source enumeration, complete original field15 source grammar, or rejected/unvisited paths in a real VM. A production observer needs an independently authenticated enumeration population and coverage boundary, including rejection *before* owner resolution.
- **COVERAGE-03 — OPEN / HIGH:** Original image ordering, metadata handle ownership and byte-length/declaration fields are supplied synthetic facts; the real `MetadataLifetimeGate.Reader`, `g_MetadataLock`, class lifetime/GC and metadata-write fences remain unbound. Matching passes and `Reader.Epoch()==1` cannot prove whole-VM linearization or GC provenance.
- **COVERAGE-04 — OPEN / HIGH:** Every bounded host lookup remains potentially O(number of physical image TypeDefs); the loop visits are capped, not performance-accepted. No measured Unity worker-stack size, metadata-lock latency, allocator overhead, RSS, 32-bit ABI, or game-source high-water count. The 1,024/4,096 prototype caps are **not** production capacity recommendations.
- **COVERAGE-05 — OPEN:** Late omissions can revoke only an in-memory trace, not a previously exported JSON or external receipt. No native V2 artifact/envelope, independent readback and first recovery; no terminal-safe full original V1 field14/15. The existing historical R03 full-stage FAIL/High findings and unrelated R02 byte-pin CI mismatch remain open.
