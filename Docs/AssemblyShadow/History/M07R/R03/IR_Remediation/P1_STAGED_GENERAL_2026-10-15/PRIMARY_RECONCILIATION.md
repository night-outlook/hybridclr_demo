## Implemented native P1 component

1. **libil2cpp/vm/AssemblyShadowFrozenGeneralCapture.h**: a one-use, noncopyable, nonmovable builder owning its complete **original general-diagnostics V1 JSON bytes** in one fixed 3,932,160-byte buffer. Preallocate while healthy; caller retains exclusive single-thread ownership.
2. Typed **Header, Transaction, AssemblyRow, EventRow, UseRow, OrdinaryAssemblyRow and OrdinaryClassRow** interfaces consume borrowed string/enum/scalar data synchronously and serially in the unchanged V1 field and array order. An internal strict stage machine prevents missing, duplicate, reordered or post-completion arrays; all variable text is serialized/captured immediately, never retained as a source string or raw VM pointer.
3. The source uses the existing exact native QuotedText writer and original AssemblyShadowDiagnostics::StateName/UseKindName tokens; it preserves boolalpha, original capability/schema keys, state/error precedence *when supplied by the caller*, both independent enumeration generation fields, all class/assembly/use/event fields and number widths. It verifies complete UTF-8 at Freeze. **Borrowed data lifetime is the caller's responsibility during each synchronous method invocation.**
4. The writer can retain a bounded *prefix* internally during an unsuccessful build but exposes neither data nor a complete receipt until Freeze succeeds; error state remains terminal. The caller must not interpret an earlier stage-method true as completion (some writer-budget errors become visible at Freeze). Invalid stage, null/buffer-aliased inputs, invalid UTF-8 and capacity failure reject the record. No automatic retry or truncation is permitted.
5. The frozen record's EmitTo performs a whole-length capacity check *before any sink callback*, then replays at most **65,536 bytes per callback**. A sink failure can leave a physical partial prefix but returns incomplete, not an accepted record; the caller must never treat that prefix as a valid artifact. Subsequent emission reads only the owned bytes, independent of the source snapshot lifetime.
6. This is an **unencoded field14 buffer** bounded by the V2 artifact maximum, not a general-field exclusive share of that artifact and not a peak-process-memory proof. Both complete actual fields, frame overhead, authenticated identity and exact aggregate must later satisfy the unchanged codec/transaction limits.
