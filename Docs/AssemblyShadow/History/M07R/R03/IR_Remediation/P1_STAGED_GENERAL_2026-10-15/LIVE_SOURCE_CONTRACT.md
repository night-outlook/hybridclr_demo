## Invariants before calling a frozen record a real P1 VM capture

1. No C#/managed callbacks, VM business dispatch, metadata type or generic instantiation, GC finalizer suppression, recursive class initialization, or unreviewed engine owner calls during acquisition.
2. Frozen record must contain **all** original fields and each required element in original insertion order, without truncation, deduplication, dropped observations, omitted invalid text, invented generations, or relaxed semantics.
3. All text must be copied under an explicitly reviewed source-lifetime contract. No borrowed name, class, image or type-key pointer may survive the owner boundary into output or the file sink.
4. Source-ordering must be preserved: transaction snapshot, first-guard failure precedence, baseline first uses, physical assembly enumeration generation, class enumeration generation and R02 counters are presently **distinct** source epochs. A single global epoch must NOT be asserted without source-level quiescence evidence. Preserve both generation fields and original coverage/error semantics even if independently sampled.
5. Every failure (lock/lifetime not admitted, version changed, no owner, capacity exhausted, invalid UTF-8 or I/O failure) is fail-closed and attributable; no bounded prefix becomes a complete semantic field.
6. The previously immutable SNAP-01 report predicates, V1 individual262144 text limit, V2 frame65536 / artifact3932160 / envelope262144 / encoded total4194304, and engine500ms/1–64 uncapped reporting must not change.

## New staged general owned record

Native AssemblyShadowFrozenGeneralCapture.h uses one preallocated 3,932,160-byte general JSON buffer and an internal no-heap incremental writer. It consumes QuotedText synchronously: Begin + startup names, transaction status + closure, stable AOT, commit order, assemblies, events, baseline uses, separate physical assembly generation, ordinary assemblies, class generation, ordinary classes and Freeze. Stage order ensures all schema arrays are present exactly once. Typed row values are serialized immediately; nothing references the source after the method returns. Freeze rejects invalid UTF-8, incomplete order and overflow and does not expose a prefix as a valid record. EmitTo prechecks known total size and replays <=65536-byte chunks into an independently owned sink. Failed sink writes may leave bytes in that sink; WriteResult.complete=false is mandatory.

This is a **general output-owned record**, not a real runtime VM census. The maximum general buffer is the V2 *artifact* allowance, not the available general-field share when field15 and framing also occupy the artifact. A future source-backed native V2 transaction must enforce exact aggregate wire-size, complete field14+15 and authenticated run/source/PID/build identity before publishing any descriptor. Storage was allocated in host tests before the capture; production pre-arm/peak RSS remains unqualified.
